# Future AI Academy — Notes

_Last updated: 2026-11-10_

## Future course: Agentic AI

**Goal:** Teach students to build AI agents: AI systems that plan, use tools and take actions on their own to complete a task.

**Status:** Idea / planned for the future

### Draft outline (to refine later)
1. **What is an AI agent?** How chatbots, assistants and agents differ, with real-world examples
2. **LLM basics.** Prompts, tokens, context and model choice
3. **Tool use.** Letting the model call functions and APIs (weather, search, calculator)
4. **The agent loop.** Plan, act, observe, repeat
5. **Memory and knowledge.** Short-term context, long-term memory and RAG (retrieval)
6. **Multi-agent systems.** Agents that hand work to other agents
7. **Safety and guardrails.** Permissions, human approval and testing agents
8. **Final project.** Each student builds and demos their own agent

### Ideas
- Use free APIs from the public-apis list (see below) as the "tools" students' agents call
- Hands-on coding in the browser (Judge0 code playground)
- Possible levels: Beginner (no-code agents) → Intermediate (Python) → Advanced (multi-agent)
